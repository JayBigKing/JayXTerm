终端编码与 Vim

底部选择的是 SSH 输入和输出的编码。文件编码与终端编码可以不同；Vim 的 termencoding 必须与底部选择一致。

终端选 GBK 时，在 Vim 中执行：

:set encoding=utf-8 termencoding=cp936

终端选 UTF-8 时，在 Vim 中执行：

:set encoding=utf-8 termencoding=utf-8

如果 GBK 文件被 Vim 误判，确认没有未保存修改后，重新按 GBK 读取：

:edit ++enc=gbk

保存原有 GBK 文件时应保留 fileencoding=cp936（或 gbk）。编码切换只影响后续终端输出；可用 Ctrl+L 重绘。SFTP 始终传输原始文件字节，不转换文件内容。
